when the code changes.

  `tools/gen_rule_docs.py`).
- [Analyzer reference](analyzers.md) — the 9 built-in analyzers with metadata,
  run order, and selection semantics from `orchestration/analyzers.py`.
- [SDK surface](sdk.md) — the stable `attackmap.sdk` contract exports from
  `sdk/__init__.py`.
- [Detection quality](detection-quality.md) — AR048 evaluation baseline
  (published by the detection-quality harness, not by AR068).
